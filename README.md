
# 💚 Sehat Saathi AI

### Your Intelligent Healthcare Companion

Sehat Saathi AI is a bilingual, multi-agent healthcare
assistant powered by Groq AI and Streamlit.

## Features

- Medical report explanation
- Experimental X-ray image understanding
- Medicine image identification
- Medicine information using OpenFDA
- AI health chatbot
- Urdu and English language support
- Voice input and spoken responses
- AI diet and nutrition guidance
- Medical health summaries

## Technology Stack

- Python
- Streamlit
- Groq API
- GPT-OSS 120B
- Qwen Vision
- Whisper
- PyMuPDF
- Google Text-to-Speech

## Project Architecture

The application uses specialized agents for
medical reports, medicine information, health chat,
nutrition, summaries and voice interactions.

## Deployment

Deployed using Streamlit Community Cloud.

## Disclaimer

This project provides educational health information.
It does not replace qualified medical professionals,
radiologists, pharmacists or emergency services.

Medical image interpretation is experimental.
